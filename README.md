# AnimalForest64-Recomp

A native PC recompilation project for the classic N64 game **Animal Forest (Dōbutsu no Mori)**.

This project utilizes [N64Recomp](https://www.google.com/search?q=https://github.com/n64recomp/n64recomp) to allow the game to run natively on modern hardware, providing better performance and support for higher resolutions.

### ⚠️ Legal Disclaimer

This project **does NOT include the game ROM**. To compile and run this project, you must possess a legal copy of the original *Dōbutsu no Mori (N64)* ROM. This repository provides only the source code and the tools necessary to perform the recompilation from your own copy of the ROM.

### How to Compile

1. Ensure you have all the required dependencies for N64Recomp installed.
2. Place your original ROM (named `baserom.z64`) in the root directory of the project.
3. Run the build script:
```bash
python3 build.py

```



### Features

* **Native Execution:** Play the game without needing an emulator, with superior performance.
* **Preservation:** Maintains the fidelity of the original game on modern hardware.
